# `CLAUDE.md` の雛形

このディレクトリには、顧客リポジトリへ配る `CLAUDE.md` の雛形を置きます。
配り先が分かるように、リポジトリ内の位置と同じ形にしています。

| ファイル | 配り先 |
|:--|:--|
| `root/CLAUDE.md` | `CLAUDE.md` |
| `client/CLAUDE.md` | `client/CLAUDE.md` |
| `server/CLAUDE.md` | `server/CLAUDE.md` |

案件固有の節（識別子の体系、絶対に守るルール、DB のロールなど）は
**空の雛形**として残し、`/shinnn-app:feature` の初回で埋めさせます。
